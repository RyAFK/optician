# Hero photography

`hero-practice.svg` is a placeholder wash, not real photography. Replace it
(update `heroImageSrc` in `components/Hero.tsx`) with an authentic photo of
the practice — an optometrist mid-examination, the fitting room, or a
genuine patient portrait (with consent). Aim for a 4:5 portrait crop,
1200×1500px or larger, saved as `.jpg` or `.webp`.
